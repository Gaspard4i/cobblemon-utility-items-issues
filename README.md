# Cobblemon Utility Items, issues

Bug tracker for **Cobblemon Utility Items**, a Cobblemon addon for Minecraft 1.21.1 on NeoForge and Fabric.

Open an issue for a bug or a suggestion. Please give the mod version, the Cobblemon version, the loader and, for a crash, the log.

Download: https://modrinth.com/mod/cobblemon-utility-items
